# Evidence

Proof for the report's technical appendix and the demo. Save files here as you finish each work package.

- Screenshots: name them `<WP>-<what>.png`, e.g. `3.1-mfa-login.png`, `3.4-ciphertext-in-db.png`.
- Command output: paste into a `.txt` file, e.g. `2.3-attack-sh-output.txt`, `3.3-curl-headers.txt`.

Never save real passwords, keys, TOTP secrets or decrypted personal data here: this repository is public.
